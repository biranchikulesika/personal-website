# Biranchi Kulesika

The source code behind my personal website, [biranchikulesika.com](https://biranchikulesika.com).

This is where I build, experiment, and refine the systems behind my website. The project combines the public-facing site with a custom publishing system, admin interface, content management, authentication, and supporting infrastructure.

## What you'll find

* Custom editorial interface and design system
* Next.js and React application
* TypeScript and Tailwind CSS
* MDX-based publishing system
* Supabase and PostgreSQL
* Custom admin and content management tools
* SEO, structured data, and Open Graph generation
* Authentication and access control
* Razorpay payment integration
* Automated tests and production-focused architecture

The structure and implementation reflect how I currently like to build things. Some parts are highly specific to my website, while others may be useful as ideas or inspiration for your own projects.

## Architecture

```text
UI
 ↓
Services
 ↓
Repositories
 ↓
Database
```

The codebase is organised around clear boundaries between the interface, application logic, data access, and persistence.

## Tech Stack

**Next.js · React · TypeScript · Tailwind CSS · Supabase · PostgreSQL · MDX · Zod · Razorpay**

This repository is a snapshot of an ongoing project. The code will evolve as the website evolves.
