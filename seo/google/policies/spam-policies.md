# Spam Policies

Google's spam policies define behaviors that can lead to lower ranking or removal from search results.

## What Google says

### Key spam tactics to avoid

| Tactic | Description |
|--------|-------------|
| **Cloaking** | Showing different content to Google than to users |
| **Doorway pages** | Pages created specifically for search engines, not users |
| **Hidden text/text links** | Text hidden from users but visible to crawlers |
| **Keyword stuffing** | Unnaturally repeating keywords to manipulate ranking |
| **Link spam** | Buying/selling links, excessive link exchanges, link schemes |
| **Hidden redirects** | Redirecting users to a different page than what Google sees |
| **Scaled content abuse** | Mass-producing content (including with AI) without adding value |
| **Scraped content** | Copying content from other sites without adding value |
| **Sneaky redirects** | Redirecting to a different page than what the user expected |
| **User-generated content spam** | Not moderating comments/forums for spam links |

### Consequences

- Lower ranking for individual pages
- Lower ranking for the entire site
- Complete removal from Google's index
- Manual actions (requiring reconsideration request)

### What is NOT a violation

- Having duplicate content (inefficient, but not a violation)
- Having links from low-quality sites (you can't control who links to you)
- Not having the "best" content for a query

## What this means for this website

This site has no spam concerns because:
- All content is original, personal writing
- No paid links or link schemes
- No cloaking or hidden content
- No doorway pages
- No user-generated content (no comments, forums)
- No mass-produced content

The main thing to watch: if AI tools are used for content creation, ensure the content provides genuine value and isn't mass-produced without quality.
